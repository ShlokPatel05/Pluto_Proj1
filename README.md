# Netflix Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

## Objective

Analyze Netflix content, clean the dataset, visualize trends, and generate business insights.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset

Netflix Movies & TV Shows Dataset

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Visualization
5. Insights Report

## Visualizations

* Bar Chart
* Horizontal Bar Chart
* Line Chart
* Histogram
* Pie Chart
* Heatmap

## Key Insights

* Movies dominate Netflix content
* United States contributes the most content
* Modern content appears more frequently
* Release years peaked around 2018
* Recent releases dominate the dataset
